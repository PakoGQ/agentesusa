# Reportes — Marco (Contadores)

> Marco genera dos tipos de reportes principales: **semanal** (en temporada de impuestos) y **mensual** (fuera de temporada). Más reportes ad-hoc según el paquete contratado.

---

## Reporte de Capa 3 — Solo Pro y Elite (mensual + trimestral)

### Mensual — Dashboard ejecutivo

Incluye lo del reporte mensual + análisis avanzado:

- Tendencias YoY (este mes vs mismo mes año anterior)
- Análisis de rentabilidad por tipo de cliente
- Identificación de clientes en riesgo de churn (señales: respuestas tardías, quejas, pagos atrasados)
- Forecasting de carga de trabajo próximos 90 días
- Benchmarking vs ratios saludables del sector

### Trimestral — Reporte estratégico (Elite)

- Análisis de capacidad: ¿el despacho necesita contratar?
- Análisis de pricing: ¿algún cliente debería estar en paquete distinto?
- Análisis de servicios: ¿hay un servicio que pide la mayoría y no se ofrece?
- Recomendaciones de cambios operativos basadas en data acumulada

## Configuración técnica en Make.com

| Reporte | Cron | Trigger condicional |
|---------|------|---------------------|
| Semanal temporada | Lunes 7am | Si `tax_season_active = TRUE` |
| Diario abril | L–V 7:30am | Si fecha está entre 1–15 abril |
| Mensual fuera temp. | Primer lunes 9am | Si `tax_season_active = FALSE` |
| Mensual Capa 3 | Primer lunes 10am | Si paquete = Pro o Elite |
| Trimestral Elite | Primer lunes de Q (ene/abr/jul/oct) 11am | Si paquete = Elite |

Cada cron lanza un escenario de Make.com que:
1. Query a Supabase para obtener métricas del período
2. Llama a Claude API con system prompt + datos crudos
3. Renderiza email y WhatsApp
4. Envía y marca como entregado en Supabase
