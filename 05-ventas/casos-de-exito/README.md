# Casos de Éxito

> Esta carpeta se llena conforme firmamos clientes y obtenemos resultados documentados. Empezamos vacíos — el primer caso por vertical es la prioridad.

---

## Estructura de cada caso de éxito

Cada caso se documenta en su propio archivo con esta plantilla:

```
[NUMERO]-[VERTICAL]-[NOMBRE_CLIENTE].md
```

Ejemplo: `01-contadores-despacho-rivera.md`

## Reglas de uso de casos

1. **Nunca usar un nombre de cliente sin permiso escrito.** Cláusula explícita en el contrato.
2. **Anonimizar siempre** screenshots de conversaciones (cambiar nombres, números, datos sensibles).
3. **Cuantificar el ROI** siempre que sea posible. "Mejoró el servicio" no vende; "12 horas/semana liberadas" sí.
4. **Cliente piloto recibe descuento** (50% setup) a cambio de:
   - Permiso completo para caso de éxito
   - Quote textual con foto
   - Llamada de referencia con 3 prospectos en los primeros 6 meses
   - Video testimonial de 60 seg
5. **Solo el primer cliente por vertical** recibe el descuento. Los siguientes pagan precio completo aunque también firmen permiso de caso.
