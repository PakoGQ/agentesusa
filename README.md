## Lo que tú haces (lo indispensable)

1. **Constituir la LLC en Wyoming** y abrir Mercury Bank → ver [01-empresa/legal-llc-wyoming.md](01-empresa/legal-llc-wyoming.md)
2. **Identificar 3 prospectos** en tu red personal (contadores o abogados) → ver [08-roadmap/semanas-1-4.md](08-roadmap/semanas-1-4.md)
3. **Hacer la llamada de diagnóstico de 90 min** con cada prospecto → ver [06-onboarding/checklist-cliente-nuevo.md](06-onboarding/checklist-cliente-nuevo.md)
4. **Decidir el nombre definitivo** (provisional: Nexus) → ver [08-roadmap/decisiones-pendientes.md](08-roadmap/decisiones-pendientes.md)

Todo lo demás (system prompts, copy, flujos, plantillas, configuraciones) ya está desarrollado en este repo.
